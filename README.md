## Research Question

Are adolescent autonomy, parental closeness, parental involvement, and family connection are associated with adult mental health, physical health, income, and financial security.

## Project Structure

- `paper/paper.qmd`: Quarto source file for the paper
- `paper/paper.pdf`: Rendered PDF report
- `paper/references.bib`: Bibliography file
- `data/` — Local data files, excluded from GitHub using `.gitignore`
- `.gitignore` — Files excluded from the repository

## Data

The data is from National Longitudinal Study of Adolescent to Adult Health (Add Health) Wave I and Wave 4.

Wave I: https://dataverse.unc.edu/dataset.xhtml?persistentId=doi:10.15139/S3/11900

Wave IV: https://dataverse.unc.edu/dataset.xhtml?persistentId=doi:10.15139/S3/11920

Note that the data is not included in this repository. It is available for public use at Add Health Dataverse. The data is in SPSS format (`.sav`) and requires the `haven` package to read.
